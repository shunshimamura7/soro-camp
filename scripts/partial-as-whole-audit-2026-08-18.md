# 棚卸し —「部分を全体と取り違える」型（§22）の洗い出し（2026-08-18）

**洗い出しのみ。1行も直していない。**優先度だけ付けてある。

観点は4つ。**件数の上限 / ページング / 最初の1件で確定 / 上限を呼び出し元に返していない。**

3列の意味:

- **上限があるか** … 全体の一部しか見ない箇所か
- **明示されるか** … 切ったことが**出力に出るか**（人が気づけるか）
- **母集団に影響するか** … MISSING/IN_DATA/ORPHAN・件数・判定を動かすか（**表示だけなら影響なし**）
