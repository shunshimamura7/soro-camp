# 対照群との比較 — ORPHAN は本物か、ソースが弱いだけか

H-3 で「needsVerify 14件の所在地区は群Aの全部で IN_DATA が0〜1件」という結果が出たが、
**母集団を needsVerify から取っているので循環している。**疑わしいレコードの所在地区を集めれば、
一致しない地区ばかり集まるのは当然で、地区固有の汚染とは切り分けられない。

そこで **needsVerify が1件も無い地区**を対照群として同じ検査にかけた。

生成物:

- needsVerify 群 … `scripts/sweep-summary-2026-08.md`（`--all`）
- 対照群 … `scripts/sweep-control-2026-08.md`（`--district` を10個並べた実行）

**この md だけは手で書いている。**上の2本は `district-sweep.js` が生成するので、
再実行すると上書きされる。比較の結論はそちらに書けない。

## 対照群の選び方

- 群A（L1 が1つ以上ある市町村）に限る
- その地区に **needsVerify が1件も無い**
- データ内の施設が2件以上（1件の地区は一致率が0%か100%にしかならず、比較に使えない）

条件を満たした地区は27個あり、そのうち**データ2件以上の10地区すべて**を採った
（恣意的な抽出を避けるため、上位10件ではなく「2件以上の全件」がちょうど10地区だった）。

**厚木市と松田町からは1地区も取れていない。**この2市町には needsVerify を含まない
地区が無く、対照群は 相模原市4・富士河口湖町3・山北町2・川根本町1 の配分になっている。

## 結果

| 群 | 地区数 | データ内 | IN_DATA | ORPHAN | **一致率** |
|---|---|---|---|---|---|
| needsVerify 群（群A） | 7 | 10 | 2 | 8 | **20%** |
| **対照群** | 10 | 26 | **20** | 6 | **77%** |

Fisher の正確確率検定（両側）で **p = 0.0055**。

**結論: 後者。needsVerify 群の一致率の低さは本物で、この検査の誤検出だけでは説明できない。**

対照群では10地区中6地区が一致率100%で、L1 は普通に施設を拾えている。
同じソース・同じ名寄せを使って needsVerify 群だけが 20% に落ちるので、
**「L1 の網羅性が低いだけ」という説明は成り立たない。**

したがって `district-sweep.js` は MISSING 専用の道具に格下げしない。
**ORPHAN も選別の手がかりとして残す。**

## ただし ORPHAN の誤検出率はゼロではない

対照群でも ORPHAN が6件出た。

| id | status | priceVerified | officialUrl |
|---|---|---|---|
| `mitsumata-camp` | active | true | なし |
| `okooigawa-lake` | active | true | なし |
| `sumatakyo-camp` | active | true | なし |
| `sagamiko-pleasure-camp` | active | true | なし |
| `sports-train-aokigahara` | **closed** | – | なし |
| `fujigane-kogen` | **closed** | true | なし |

- **closed の2件は出て当然。**閉業した施設は自治体・観光協会の現行一覧から消える。
  ORPHAN は閉業施設を必ず拾うので、**status=closed のレコードに対しては情報量がない**
- 残る **active 4件は誤検出**。対照群の active レコード24件に対して **17%**

**つまり ORPHAN は「6件に1件は実在する施設を撃つ」。**
§6-7 のとおり、これ単独で `status` を動かす根拠には絶対にならない。
絞り込みの入口としてのみ使う。

## I-2. L1 ごとの網羅率

「一覧に載らない実在施設がどれくらいあるか」を L1 ごとに実測した（`--l1-coverage`）。
母数は `priceVerified: true` かつ `needsVerify` なし＝実在がほぼ確実な群。
結果は `sweep-l1-coverage-2026-08.md`。

| L1 | 網羅率 | ORPHAN 判定 |
|---|---|---|
| 相模原市観光協会 | **79%**（11/14） | **使える** |
| 相模原市 ミドナビ | 64%（9/14） | |
| 川根本町公式 | 63%（5/8） | 使えない |
| 山北町観光協会 | 57%（4/7） | 使えない |
| 山北町公式 | 43%（3/7） | |
| 富士河口湖町観光連盟 | 27%（3/11） | 使えない |
| 厚木市観光協会 | 0%（0/1・母数1） | 使えない |
| 松田町公式 | 0%（0/1・母数1） | 使えない |
| 伊東市・山梨市・南部町 | L1_NOT_FOUND | 使えない |

**7割を超えたのは相模原市観光協会だけ。**
`district-sweep.js` は、7割以上の L1 が1つも無い市町村では ORPHAN を
「⚠ 判定に使えない・参考値」として出すようにした。

**牧野は相模原市なので、ORPHAN が判定として読める唯一の地区群にあたる。**
`kabutomushi-mori-camp` / `okumakino-camp` の ORPHAN は他の地区の ORPHAN より重い。

網羅率は**下限値**。名寄せがローマ字と かな を越えないので、
`camp-akaike`（データ名「CAMP AKAIKE」）が一覧の「キャンプあかいけ」と照合できず落ちている。
実際の網羅率はこれより高い。**ORPHAN を「使えない」側に倒す誤差なので安全側。**

## I-3. 名前フィルタを本文判定に replaced — 効果はほぼ無かった

厚木市観光協会と富士河口湖町観光連盟の L1 は宿泊施設の混在一覧で、
機械で読めるジャンル表示が無い。名前に「キャンプ」が入るかで絞っていたため、
「亀見橋バカンス村」型が漏れる懸念があった。

**詳細ページの本文にキャンプ関連語（キャンプ/テント/オートサイト/バンガロー/野営）が
あるか**で判定する方式に替えた。採用前の実測:

| ページ | 結果 |
|---|---|
| 亀見橋バカンス村（e-sagamihara camp-627） | **PASS**（キャンプ・テント） |
| 藤野芸術の家（e-sagamihara camp-668） | **PASS**（キャンプ・テント） |
| 四季の宿 富士山（fujisan.ne.jp） | 落ちる（正しい） |
| 厚木市観光協会の宿・ホテル23件 | 全件落ちる（正しい） |

### 途中で踏んだ罠 — 判定範囲を切らないとページ下部で汚染される

最初の実装はページ全体を見ていた。結果、富士河口湖町の L1 が 16件 → **58件**に増え、
小立の MISSING HIGH が 0 → 4 になった。**増えた4件は「あおい荘」「湖畔荘」「紅富士荘」
「レジーナリゾート富士」で、全部ただの旅館・リゾートホテルだった。**

原因はページ下部の「おすすめスポット」枠。隣に表示された**別のキャンプ場の紹介文**を
拾っていた。しかも**この枠は取得のたびに中身が変わるので、同じページが通ったり落ちたりする。**

`<h1>` から「おすすめスポット」の手前までに判定範囲を切って解決。

### 切った後の結果

| | 名前フィルタ | 本文判定（範囲を切った後） |
|---|---|---|
| 厚木市観光協会 の一覧件数 | 1 | 1 |
| 富士河口湖町観光連盟 の一覧件数 | 16 | 17 |
| 富士河口湖町小立の MISSING | 7（HIGH 0） | 7（HIGH 0） |
| 富士河口湖町の網羅率 | 27% | 27% |

**この2市町では実質的な収穫が無かった。**
判定方式としては本文判定のほうが正しい（名前に依存しない）ので採用したままにするが、
**小立で L1 由来の MISSING が0なのは、フィルタのせいではなく
富士河口湖町観光連盟の一覧にそもそもキャンプ場が少ないため**だった。

## この比較の限界

- **N が小さい。**needsVerify 群のデータ内はわずか10件。p=0.0055 は出ているが、
  1〜2件の判定が変わるだけで印象が変わる大きさ
- **対照群に厚木市・松田町が入っていない。**この2市町の L1 は弱い（厚木市観光協会は1件、
  松田町公式は1件）ので、対照群の一致率77%は**L1 が強い市町村に寄っている**
- needsVerify 群の地区はデータ内1〜2件の地区が多く、1件外すと一致率が0%か100%に振れる
- **needsVerify フラグ自体が過去の判断の産物**で、独立した基準ではない。
  この比較は「フラグが当たっていたか」を見ているのであって、
  「地区単位で捏造されたか」を直接見てはいない
