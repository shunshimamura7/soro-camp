## 2. FORBIDDEN を実装した

### 変更点

**`district-sweep.js`**

1. `collectSource` の `status` に **`FORBIDDEN`** を追加。判定順は指示どおり
   **`SKIPPED_ROBOTS` → `FORBIDDEN` → `RATE_LIMITED` → `UNREACHABLE`**
2. 戻り値に `forbidden: [{url, detail}]` を追加（`rateLimited` と同じ形）
3. `incompleteNote` を 429 専用から一般化。`total/list/detail/urls` は**429と403の合計**で
   既存の呼び出し側の意味を保ちつつ、内訳を `byReason.rateLimited` / `byReason.forbidden` に持たせた
4. 地区 md の「ソースの取得結果」表で、**`OK` 以外は件数欄に数字を出さない**
   （`**測れず**（0）` と書く）。`FORBIDDEN:0` が「そこに無かった」と読めるのを潰す
5. `fetchPage` の note の説明に `HTTP_403` の行を追加

**`dropped-buckets-all.js`**

6. 先頭の「この実行は不完全」バナーで**429と403を分けて出す**。
   **403 は「再実行しても変わらない／UA を偽装して回避しない」と明記**
   （429だけ「時間を空けて再実行」と書く）

**`fetchPage` は変えていない。**403 はもともと `HTTP_403` として note に残り、
`res.status !== 429` で即 return するので**再試行しない**——実装済みの挙動がそのまま要件を満たす。

### 偽ゼロ検証 — `scripts/.mock-forbidden-test.js`（18件 OK）

```
■ (a)(b) 一覧が 403
  ✅ status が FORBIDDEN / ✅ UNREACHABLE ではない / ✅ RATE_LIMITED ではない
  ✅ 403 は再試行しない（1回だけ） / ✅ forbidden に記録が残る / ✅ items は空
■ (c) 403 と DNS 死が混ざらない
  ✅ DNS 死は UNREACHABLE のまま / ✅ DNS 死に forbidden は付かない
■ (d) 同じソースに 403 と 429   ✅ FORBIDDEN が優先 / ✅ 429 も rateLimited に残る
■ (d2) robots で止めたもの      ✅ SKIPPED_ROBOTS が最優先
■ (e) 偽ゼロ検証
  ✅ incompleteNote が null にならない / ✅ forbidden として数える / ✅ rateLimited は0
  ✅ **items 0件でも status が OK ではない**
■ (f) robots.txt は200・Crawl-delay ありなのに本体が403（1059dai.com 型）
  ✅ robots が通っても本体403なら FORBIDDEN / ✅ SKIPPED_ROBOTS にはならない
```

既存の `.mock-ratelimit-test.js`（18件）も**そのまま PASS**、
`district-sweep` の自己検査・`chiba-sources` の自己検査も OK。

### 残した課題（実装していない）

**robots.txt 自体が403のオリジンを踏み続ける問題。**
`getRobots` は `res.ok` でなければ「制限なし」に倒すので、
`japancamp.jp` のように robots を403で拒否しているサイトを1秒間隔で叩き続ける。
RFC 9309 上は 4xx を「制限なし」と読んでよいが、**403 は「あなたには見せない」の明示**なので
オリジンごと止めたい。`getRobots` の戻りに `forbidden: true` を足して
`fetchPage` が `SKIPPED_ROBOTS` 相当で止める形が素直。**今回は入れていない。**

## 3. ドメイン失効の検出 — 既存判定は**素通りする**。ただし既存188件に該当は0件

### 既存 `check-official-urls.js` は峰山型を捕まえない（実測）

`PARKED_PATTERNS` は13語。**峰山の売却ページ（9,161字）に対して一致 0件。**

理由は**文言が完全一致を前提にしている**こと:

| 既存パターン | 実際のページにある文字列 |
|---|---|
| `This domain is for sale` | `For sale` / `Available —` |
| `Domain for sale` | `Premium domain` |
| `Buy this domain` | `Buy-it-now $195 USD` / `Buy ForestPartyMineyama.com` |
| （マーケットプレイス名なし） | `Afternic` / `GoDaddy` / `checkout` |

**「200 が返る＝生きている」ではない**うえに、
**既存の PARKED 判定も通してしまう。**峰山は `DEAD` にも `PARKED` にもならず `OK` 判定になる。

### 既存188件の実測 — パーキングは0件

`scripts/.parked-scan.js` を書いて `officialUrl` を持つ**116件**を実測した
（**UA は ClaudeBot のまま。偽装しない**。既存スクリプトは Chrome UA を名乗る）。

```
既存判定で PARKED : 0
提案判定で PARKED : 0
提案だけが拾った  : 0
既存だけが拾った  : 0
```

**現時点で、既存データの公式URLに売却・パーキングページは無い。**

> **ただしこれは下限。**23件が403で中身を見られていないので、
> **「0件」は「見えた92件に無かった」という意味。**
> §2 で足した FORBIDDEN の理屈が、そのままこのスキャン自身にも当てはまる。
> Chrome UA を名乗る既存スクリプトなら23件も見えるので、
> **本番の判定は既存スクリプト側に入れるのが筋。**

### 提案する検出方法（実装はまだ）

**単語の一致ではなく「売り物になっている兆候の同時出現」で見る。**
`.parked-scan.js` に試作を入れてある。

```js
const PARK_MARKETPLACE = /(afternic|sedo|dan\.com|godaddy|hugedomains|bodis|
                           namecheap market|porkbun|お名前\.com|さくらのレンタルサーバ)/i;
const PARK_SELL        = /(buy[- ]it[- ]now|buy this domain|domain (?:is )?for sale|
                           premium domain|make an offer|ドメインの有効期限)/i;
const PARK_SUSPEND     = /(account suspended|このサイトは現在準備中|サービス提供を終了|
                           connectyourdomain)/i;
```

判定は3段:

1. `PARK_SUSPEND` に当たれば即 PARKED（停止・準備中）
2. **`PARK_MARKETPLACE` と `PARK_SELL` の両方**に当たれば PARKED
   ← 片方だけだと、キャンプ場が「ドメイン」の語を含む記事を書いたときに誤爆する
3. `PARK_SELL` だけでも**本文が 20,000 字未満**なら PARKED（薄い売却ページ型）

**既存の13語は消さずに残す**（`ConnectYourDomain` など今も効くものがある）。
上の3段を**足す**形にすれば、峰山型が `PARKED` で立ち、既存の判定も変わらない。

**もう1つの案（併用を推す）: 自治体公式のリンク切れを別に数える。**
君津市公式のキャンプ場一覧14件のうち、**リンク先が壊れているものが3件**あった。

| 施設 | 君津市公式のリンク | 実際 |
|---|---|---|
| フォレストパーティー峰山 | `forestpartymineyama.com` | **失効・売却中**（現公式は `.jp`） |
| ホウリーウッズ久留里 | `holywoodscamp.jimdo.com` | **TLS失敗**（現公式は `jimdofree.com`） |
| 柿山田 | `...hello-net.info` | **DNS 消滅** |

**L1 が指す外部リンクの腐りは、L1 の質そのものの指標になる。**
`check-muni-sources.js` が L1 の入口URLを見ているのと同じ理屈で、
**L1 が持つ HPリンクの死活も測る価値がある。**
