# 千葉県 拡張の下見（2026-08-15）

**スイープは走らせていない。**ソース定義（`scripts/chiba-sources.js`）を作り、
L1 の質と robots.txt を実測しただけ。**`MUNI_SOURCES` には接続していない**
（`node -e` で確認済み。登録市町村は18のまま、既存の自己検査も OK）。

接続は1行:

```js
Object.assign(MUNI_SOURCES, require('./chiba-sources').MUNI_SOURCES_CHIBA)
```

**案Cを決めるまでこの1行を書かない。**

## 0. なぜ止めてあるか（数字で）

`data/campgrounds.json` は全188件。内訳は **山梨72 / 静岡61 / 神奈川55 / 千葉0**。

`l1Coverage()` は `rate: truth.length ? hit/truth : null` で、
`truth` は「その市町村の `priceVerified:true` かつ `needsVerify` なし」のレコード。
**千葉は分母が0なので `rate` は常に `null`。**`orphanTrustable()` は
`rate >= 0.7` を要求するので**必ず false。**

つまり千葉では、いま走らせても

- 網羅率は**測れない**（低いのではなく `null`）
- ORPHAN は**原理的に判定として読めない**
- 地区はレコードから作られるので、**大字が1つも立たない**

既存3県の126件の穴が「一部の大字が測られない」だったのに対し、
**千葉は全部が測られない。**懸念は当たっている。

### L1-a 千葉県 公立社会体育施設一覧・キャンプ場

`https://www.pref.chiba.lg.jp/shousupo/sports-shisetsu/r5/11campjo.html`

| | 判定 | 理由 |
|---|---|---|
| layer | **L1** | ヘッダの定義「自治体公式・観光協会・都道府県オープンデータ」に照らして、これは**社会体育施設の台帳**（施設種別・規模・バリアフリー対応まで列がある行政データ）。神奈川県公式の県央ページを L2 にしてあるのは、あれが**観光紹介の記事＋リンク集**だったから。**可逆な判断。**L2 に落としても定義の他は変わらない |
| kind | **listInline** | **詳細ページが1枚も無い。**1枚の表に 名称・所在地・規模・連絡先・電話 まで入っている。`listDetail` にすると踏む先が無い。既存で同型は大月市公式（`SRC_OTSUKI_CITY`）・キャンナビ・ウォーカープラス |

**この県だけの特殊処理が2つ要った。**

**(1) 所在地の列に市町村名が入っていない。**「緑区小食土町955」「大神保町594」。
市町村は1列目の**管理主体**から来る。既存の `addressPrefix` は
ソース単位の定数なので使えない（行ごとに違う）。主体→正式名の対応表を持った。
`長南` は長南町であって長南市ではないので、**推測で「市」を付けない**。
町村は既存データの形（「足柄上郡山北町中川」）に合わせて郡から書く。

**(2) 管理主体の市町村と施設の所在地が違う行がある。**
習志野市の「富士吉田青年の家キャンプ場」は**山梨県富士吉田市**にある。
県の一覧なのに県外が混ざる。名前でも「キャンプ場」でも落とせない。
→ 所在地が**「市」で終わる語で始まる**ときだけ域外と見て落とす。

> ここは一度踏んだ。`[市町村]` まで広げると**大字の「富浦町多田良」「大神保町594」が
> 市町村名に見えて全部落ちる。**大字が「市」で終わることはまず無いが、
> 「町」で終わる大字はいくらでもある。自己検査にこの2件を入れてある。

**実測**: 21行 → 施設列が「キャンプ場」でない行なし、県外1行を落として **20件**。
**20件すべて `districtKey()` がパースに成功**（`千葉市緑区小食土町` `長生郡長南町蔵持` など）。

### ★ 案Cに直接効く実例が1つ出た

観光協会の7件から出た地区キー:

```
南房総市千倉町白子   ← THE CHIKURA UMI BASE CAMP（千倉町白子2521-4）
南房総市白子        ← しおさいキャンプフィールド（白子2792）/ SOUTH BIRD INN（白子2591-1）
```

`inDistrict()` の大字判定は前方一致で、
`"千倉町白子".startsWith("白子")` も `"白子".startsWith("千倉町白子")` も **false**。
→ **同じ「白子」が、旧町名を書くかどうかで別地区になる。**

同じソースの同じ区間の中で表記が割れている。実在確認（南房総市に「白子」と
「千倉町白子」の両方があるのか、片方が略記なのか）は**していない。**
どちらにせよ**案Cの地区の作り方に直接効く実例**なので、決める前に見ておく価値がある。


**千葉だけの話ではない。**`PREF_SOURCES` の神奈川・静岡・山梨の
`japanCamp(...)` は**いま全部 403 で取れない。**サイト側が UA で
ClaudeBot を拒否している。

- **UA を偽装して回避することはしない**（先方が明示的に断っている）。
- 千葉の L3 に `japanCamp('12-chiba', ...)` は**入れていない。**
- 既存3県の扱い（墓標コメントを残して外すか、`UNREACHABLE` のまま置くか）は**しゅんの判断**。
  `SRC_TAKIBI` と違って**サービスは生きている**ので、廃止とは別の型。

ウォーカープラスは千葉も生きている（`ar0312` = 関東03＋千葉12、
タイトル「千葉県のキャンプ場｜ウォーカープラス」で確認）。**が、L3 は今回入れていない**
（依頼が「L2/L3: jalan / なっぷ」だったため）。入れるなら1行。
