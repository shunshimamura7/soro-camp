同じページに前年度の告知も残っていて、**2025年度は「1月4日をもちまして終了」**とある。

→ **「通年」は誤り**だが、**「11月末で完全に閉まる」も正確ではない。**
実態は「**4月中旬〜11月末が本営業。12月・年末年始は別途HPで案内（前年度は1月4日まで営業）**」。

### 1-2. `restrictions` か `season` か — **`season` の文字列を直す**

`lib/types.ts` の `Restriction` は:

```
毎年繰り返される期間限定の制限。年を持たない MM-DD で表す。
type: "bonfire" | "camping" | "access"
```

**使わないことを推す。**理由は3つ。

1. **`restrictions` は「毎年繰り返される」もの。**本栖レークサイドの営業期間は
   **年ごとに決め直されている**（2026年度は4/16〜11月末、2025年度は1月4日まで）。
   MM-DD の年なしで固定すると、**来年ずれる**
2. `type` は `bonfire` / `camping` / `access` の3値で、**「営業していない」は `camping` に近いが、
   禁止されているわけではない**（施設が閉まっているだけ）。意味が変わる
3. **`season` は既に全レコードが持っている文字列フィールド**で、
   「4月〜11月末」「3月15日〜11月30日」のような書き方が既に使われている（`yagi-camp` など）

→ **`season` を直すのが素直。**ただし「12月は別途」という条件を落とさないこと。
