## 2. ★ 先に決めること — 「市町村単位」は 18 か 20 か

**計画に入れる前に、ここを決める必要がある。**

| 単位 | 地区数 | 中身 |
|---|---:|---|
| **A: MUNI_SOURCES のキー単位** | **18** | 相模原市（緑区+中央区）/ 静岡市（葵区+清水区）を**1つ**にする |
| B: 区を分ける | 20 | 相模原市緑区 / 相模原市中央区 / 静岡市葵区 / 静岡市清水区 を別に |

**A を推す。**理由:

- **ソースが MUNI_SOURCES のキー単位で登録されている。**案Cの狙いは「ソース単位で突合する」ことなので、
  ソースの単位と地区の単位が一致するのが素直
- 区を分けると、`jalan('22101', '静岡市葵区')` と `jalan('22103', '静岡市清水区')` が
  同じエントリに同居しているので、**どちらの区の地区にも両方のソースが付く**。
  結局区の境界は効かない
- §19-5 の試算（b2 7,291 → 1,352）は **18地区**で計算されている。**基準線と揃う**

**B の利点**は、相模原市緑区（山側）と中央区（市街）で施設の性格が違うこと。
ただし**判定の粒度としては効かない**（同じソースを見るので）。
