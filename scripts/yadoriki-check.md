## 0. 前提の訂正

**依頼文の「active のままなので優先」は誤り。`yadoriki-camp` は既に `status: "unverified"` になっている。**

前回（2026-08-12）の報告で「やどりき水源林は松田町寄の実在施設なので、これも『座標だけの誤り』の
公算が高い」と書いたのは**こちらの誤り**。標高差97.6mと市町村不一致だけを見て、
レコードに既に付いている `needsVerifyNote` を読まずに判断した。
そのノートには 2026-08-11 時点で**火気禁止の一次情報まで押さえた調査**が残っており、
結論は本調査と同じ「キャンプ場ではない」方向だった。以下はその再確認と補強。

## 2. 一次情報

判定基準は「名前がヒットするか」ではなく「**予約・料金が出てくるか**」。

### 2-1. 神奈川県公式（管理者側）— 決定的

https://www.pref.kanagawa.jp/docs/pb5/j/suigen-shinrin/2/yadorikisuigenrin.html

利用上の注意として次が明記されている:

- **「たき火禁止」**
- **「キャンプ等禁止」**
- **「禁煙」**

施設の性格は**水源環境保全を目的とした森林**であって、キャンプ場ではない。
所管は神奈川県環境農政局緑政部水源環境保全課、運営は公益財団法人かながわトラストみどり財団。

**管理者自身が「キャンプ等禁止」と書いている以上、キャンプ場としての実在はあり得ない。**
これは「確認できない」ではなく「**否定された**」。§6-16 の捏造型より強い。

### 2-2. 松田町公式

- やどりき水源林 https://town.matsuda.kanagawa.jp/site/kankou-sub/yadoriki-suigenrin.html
  → 「松田町寄地区を縦断するように流れる中津川の源流域にやどりき水源林があります」。
  **所在地の表記は「松田町寄地内、中津川源流域にある水源林」で番地が無い。**
  火気・キャンプ・テント・宿泊への言及なし（＝キャンプ場として案内していない）。
- 松田町公式「キャンプ場」一覧 https://town.matsuda.kanagawa.jp/site/kankou-sub/camp.html
  → 掲載は**南丹沢清津峡キャンプ場のみ**。**やどりき水源林は載っていない。**
- 松田町公式 やどりき地区のBBQ https://town.matsuda.kanagawa.jp/site/kankou-sub/yadoriki-bbq.html
  → BBQ をするなら次の施設を使うよう案内している。
    - 寄清流マス釣り場（寄5573 / 0465-89-2321）
    - 寄自然休養村管理センター（寄3415 / 080-9572-4799）

### 2-3. 予約サイト

- なっぷ・じゃらんとも、**「やどりき水源林キャンプ場」の予約ページ・料金表は存在しない。**

### 2-4. 番地「寄3048」は引けない

GSI の住所検索は `神奈川県足柄上郡松田町寄3048` を投げても
**大字「寄」の代表点（35.405666, 139.124084）しか返さない**（番地を解決しない）。
`寄`・`寄1111-2`・`寄7138` も全て同じ代表点を返すので、**GSI では番地の実在を判定できない。**

ただし間接的な材料はある。松田町公式が寄地区で挙げる番地は
3415 / 4165 / 4380-1 / 5573 / 7138 / 1111-2 で、**3048 はどれとも一致しない**

そして**やどりき水源林そのものに番地が無い**（町公式の表記が「寄地内」）。
**「寄3048」は借用元が特定できない番地**という評価は変わらない。

## 5. 所見

**分類: 「キャンプ場ではない（unverified 落ち）」。ただし通常の unverified より一段重い。**

借用パターンC（実在するがキャンプ場でない施設）の指摘は**そのとおり**。
やどりき水源林は529haの水源林として実在するが、**管理者である神奈川県が
「キャンプ等禁止」「たき火禁止」と明記している**。

他の unverified 案件（かぶと虫の森・みつまた・山北キャンプ場）は
「実在を確認**できない**」という不在証明の弱さを抱えているが、
**この1件だけは「実在**しない**」ではなく「キャンプ場としての利用が**禁止されている**」という
積極的な否定が一次情報で取れている。** 証拠の強さが違う。

したがって:

1. **`status` は `unverified` のままでは弱い。** 既存ノートが指摘するとおり
   `closed` / `closedReason: prohibited` の検討対象。`sanogawa-camp` と同型。
   「実在が確認できたら active に戻す」という通常の unverified の含みが、
   この件では**誤って戻す危険**になる。
2. **`bonfire: true` は一次情報と正面から矛盾する。** 県が「たき火禁止」と書いている場所を
   焚き火可として掲載しているのは、利用者を違反行為に誘導しうる。
   status をどうするかに関わらず、この矛盾は残すべきでない。
3. **`priceVerified: true` は誤り。** 料金の出る経路が存在しない。
4. **`coordsVerified: true` も誤り。** 座標は松田町ですらなく山北町を指す。
5. 座標を Google ピン（35.420635 / 139.131076）に直すこと自体は可能だが、
   **キャンプ場でないものの座標を正確にしても意味がない。** 座標修正は不要というより、
   先に status を決めるべき。

### 承認をもらえれば直したい点（今回は触っていない）

- `status`: `unverified` → `closed` + `closedReason: prohibited` の是非を判断
- `bonfire: true` → `false`（または status 変更で掲載自体を落とす）
- `priceVerified: true` → 削除
- `coordsVerified: true` → 削除
- `needsVerifyNote` に本調査（**県公式の「キャンプ等禁止」**・町のキャンプ場一覧に無い・
  予約サイトに無い・座標が山北町を指す）を追記

### 別件として起票したい点

- **`mushizawa-camp` は住所の自治体が誤りの疑い**（虫沢は松田町寄の小字）。
  §4 のとおり山北町に虫沢は存在しない。実ピンを取る前に、そもそも
  「虫沢古道キャンプ場」がキャンプ場として実在するかの確認が先。
- **`hachibanaen-miroku` の住所が割れている**（データ 寄7138番 / 町公式・なっぷ 寄4380-1）。
  `tel` が空で 0465-25-5143 が入っていない。
- **`verify-coords-gsi.js` が市区町村を比較していない**（県だけ）。
  本件は address 松田町 vs GSI 山北町で、県が同じため OK で通過した。
  address から市区町村を切り出して突き合わせれば検出できる。
