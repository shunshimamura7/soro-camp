## 5. 副産物（今回の作業で見つかったもの）

### ① 大字が「内」で終わると地区キーが1文字削れる（既存のバグ）

候補②の住所を通したら、こうなった。

```
千葉県夷隅郡大多喜町堀之内595  →  地区キー 夷隅郡大多喜町堀之    ← 「内」が消える
```

`district-sweep.js:526` の

```js
.replace(/(?:地内|地先|先|内)$/, '')
```

が原因。**「敷地内」「地先」を落とす意図の規則が、裸の「内」まで食っている。**
千葉固有ではない（`市原市堀之内` でも同じ）。

**実害の範囲は測った:**

- 既存188件で影響を受けるのは **1件だけ**（`sessokyo-camp` = 川根本町犬間長嶋公園敷地内。ここは削るのが意図どおり）
- 同じ大字どうしは**両側とも同じように削れる**ので突き合わせは成立する（`堀之内595` も `堀之内1000-1` も `堀之`）
- 害は (a) md に出る地区名が壊れる (b) 「堀之内」と「堀之丸」のような別大字が同じ「堀之」に寄る衝突リスク

**直していない**（依頼の範囲外で、既存の地区キーが動くため）。直すなら:

```js
.replace(/(?:敷地内|地内|地先)$/, '')   // 裸の「内」「先」は残す
```
