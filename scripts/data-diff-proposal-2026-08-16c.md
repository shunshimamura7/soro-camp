### 1-2. ★ 「宿泊利用はできない」に反する材料がある

| URL | ページ名 |

- 「テント泊不可・バンガロー可」なら → **ソロでテントを張りに行く先ではない**が、宿泊施設ではある

### 1-3. status の判断材料 — **4値のどれも当てはまらない**

`lib/types.ts` の4値は**全部「営業状況」の軸**で、**「利用形態（何ができるか）」を表す値が無い。**

| 値 | 定義（types.ts） | 唐沢に当てると |
|---|---|---|
| `active` | 通常掲載。一覧に出る | **営業しているので事実には合う**が、テント泊できないならソロキャンプ場として出すのは誤り |
| `closed` | 閉鎖・利用禁止が確認できたもの。「もう行ってはいけない」 | **誤り。**営業している |
| `suspended` | **再開予定のある休業** | **誤り。**休業していない |
| `unverified` | **営業状況が確認できていない**もの。一覧から外し詳細に注意書き | **意味がずれる。**営業は確認できている（未確認なのは宿泊可否） |
| 削除 | — | **不可。**しゅんのルール「削除はレコードが最初から実在しなかった場合のみ」に反する。**唐沢は実在し、村公式に載っている** |

`eligibility` は「**誰が**使えるか」（甲府市民限定など）で、「**何が**できるか」ではないので使えない。
`restrictions` は「毎年繰り返される期間限定の制限」なので、これも違う。


### 2-2. 実在は自治体系2本で確認できた

| 出典 | 記載 |
|---|---|
| **山北町公式**「キャンプ場の紹介」 | **丹沢湖キャンプサイト**（7件中の1件） |
| **山北町観光協会**「自然に泊まる」 | **丹沢湖キャンプサイト / 神奈川県足柄上郡山北町玄倉490-2** |

**観光協会の住所は DB と完全一致。**神奈川県の実在施設で、**対象3県の外ではない。**
（そもそも `lib/types.ts` の `prefecture` は `"神奈川" | "静岡" | "山梨"` の union なので、
愛知のレコードは型として入らない）

### 2-3. `id` の由来 — 玄倉の読み違い

```
b817f37  feat: add batch6 36 camps (114->150)
   + "id": "kuragari-camp",
   + "name": "玄倉キャンプ場",        ← 初出時の名前
```

**玄倉は「くろくら」。**batch6 投入時に「くらがり」と読んで id を付けたと見られる。
その後 `name` は「丹沢湖キャンプサイト」に直されたが、**`id` だけ残った。**

### 2-4. 判断が要る — id を直すか

- **直す利点**: 愛知の同名施設との取り違えが再発しない（**今回まさに起きた**）
- **直す代償**: `id` は `slug` でもあり **URL になる**（`/camp/kuragari-camp`）。
  types.ts に「既存リンク対策として…ページ自体は残し」という思想があるとおり、
  **URL を変えると既存リンクが切れる。**リダイレクトの手当てが要る

**今日は触らないことを推す。**代わりに、取り違えの再発を止めるだけなら
`soloComment` か新規メモに「id は玄倉の読み違いに由来。愛知県岡崎市の『くらがりキャンプ場』とは無関係」
と1行残すのが安い。
