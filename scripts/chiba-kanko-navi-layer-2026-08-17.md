## 3. ★ L1 か L2 か — **既存の前例は「県の観光ポータルは L2」**

層の定義は「L1 一次 自治体公式・観光協会・都道府県オープンデータ」。
**字面だけなら県の観光協会なので L1 に読める。**だが既存の運用はそうなっていない。

| ソース | 実体 | 層 |
|---|---|---|
| やまなし観光推進機構（`yamanashi-kankou.jp`） | 県の観光推進機構のキャンプ特集 | **L2** |
| 神奈川県公式 県央地域のバーベキュー・キャンプ | 県公式サイトの観光紹介記事 | **L2** |
| **千葉県 公立社会体育施設一覧** | 県の**行政台帳**（施設種別・規模・バリアフリーの列がある） | **L1** |
| 相模原市観光協会 / 山北町観光協会 / 道志村役場 など | **市区町村**単位の公式・観光協会 | **L1** |

**分かれ目は「県か市町村か」ではなく「行政の台帳か、観光の紹介か」。**
`chiba-sources.js` の SRC_CHIBA_PREF_SPORTS のコメントに、
神奈川県公式を L2 にした理由が「**観光紹介の記事でリンク集が主体だった**」と書いてある。

**ちば観光ナビはスポット紹介。前例に従うなら L2。**

### 層で何が変わるか（実害の見積り）

| | L1 にした場合 | L2 にした場合 |
|---|---|---|
| `confidence` | ちば観光ナビにあるだけで **HIGH** | なっぷ・じゃらんと同じ **MID**（L2が2本以上で MID） |
| **ORPHAN の判定** | 網羅率の母数に入る。**7割を切ればその市町村の ORPHAN が「使えない」に落ちる** | 影響しない |
| `l1NotFound` | 館山市・鋸南町の「L1が1本も無い」が解消する | 解消しない |

**★ HIGH の意味が薄まるのが最大の副作用。**
木更津市の実測で**ちば観光ナビが WILDBEACH を載せていない**とおり網羅していないので、
**「県公式に載っている」を HIGH の根拠にすると、HIGH が「実在の確度」ではなく
「このサイトに載っているか」になる。**既存3県の HIGH と意味が揃わなくなる。

## 4. 推す案 — **L2 で登録する**

理由:

1. **前例に一致する。**やまなし観光推進機構・神奈川県公式と同じ性格のサイト
2. **HIGH の意味を壊さない。**網羅していないことが木更津市で実測できている
3. **情報量は層に関係なく増える。**L2 でも3件増え、きさらづの confidence も上がる
4. **可逆。**あとで L1 に上げるのは1行。上げてから下げるより安全
   （`SRC_CHIBA_PREF_SPORTS` のコメントも「これは可逆な判断」と書いている）

### L1 に上げてよい条件（測ってから）

- `--l1-coverage` で**網羅率を実測**して、7割を超える市町村がどれだけあるか見る
  （**ただし千葉はレコードが0〜3件なので母数が作れない。**当面は候補側を母数にするしかない）
- **市町村ごとのエリアコード（`56` など）を8市町ぶん確定させる。**
  いま分かっているのは木更津市 `56` だけ。**推測で番号を振らないこと**
