## 戻す3件と、その理由

### 1. `mobility-park-izu` — **検証は通った。だが候補がピンではない**

| | |
|---|---|
| 候補 | 35.00833988035657, 139.02138851545863 |
| 出典 | 施設公式 `mobility-park.jp` トップの Google マップ埋め込み `pb` の `!3d` / `!2d` |
| 検証 | 逆ジオ **静岡県 / 伊豆の国市 / 長者原** ＝ address「静岡県伊豆の国市長者原1445-481」と**大字まで一致** |
| **不採用の理由** | **その数字は地図の「表示中心」で、ピンではない**（§7-A。表示中心はピンと約200mずれる） |

**§7-A は「`@緯度,経度` は地図の表示中心で、ピンの位置とは違う」と書いている。**
埋め込みの `pb` にある `!1d…!2d<経度>!3d<緯度>` は**構造的にこの表示中心と同じもの**で、
ピンの座標（`!8m2!3d!4d`）ではない。**埋め込みの `pb` には place ID しか入っておらず、ピンの緯度経度は無い。**

**マーカー座標を出している一次情報を他に探したが見つからなかった**
（伊豆の国市観光協会 `izunotabi.com` の施設ページ・なっぷとも座標を持っていない）。

**→ 実ピンはしゅんが取る。**
**ただし現在値 35.0641/138.9267 が誤りであることは確定した**
（逆ジオが**函南町/日守**を返し、address の伊豆の国市と 10.6km ずれる）。
候補の 35.0083/139.0214 は**少なくとも正しい大字の中にある**ので、
Google マップで「モビリティーパーク」を開けばピンはこの近傍にあるはず。

## ★ 閾値を甘くしなかったこと

**一致の基準は「逆ジオの市区町村が address に現れること」で、距離では判定していない**（§6-15）。
今回は採用2件とも**大字まで一致**した。

**ここを緩めると捏造検出が死ぬ。**
`makioka-fruits-camp` は現在値と address が 17.3km 離れているが、
**「17km 以内なら OK」のような閾値を作れば、住所が捏造されたレコードにも
機械検証済みのフラグが立ってしまう。**
距離を使わず市区町村・大字の一致だけで見ているのは、まさにそれを避けるため。
