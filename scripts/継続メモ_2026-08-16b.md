## 収集層に入れたもの（この2日）

### FORBIDDEN（403）と robots ガード

- **403 を `UNREACHABLE` に畳むのをやめた。**判定順は
  `SKIPPED_ROBOTS > FORBIDDEN > RATE_LIMITED > UNREACHABLE`。403 は再試行しない
- **robots.txt 自体が403のオリジンは、UA に関係なく踏まない**（`scripts/robots-guard.js`）。
  判定は常に **ClaudeBot**。記録は `SKIPPED_ROBOTS_403`
- **代償は小さくない**（142オリジン中27件が該当）:
  - **厚木市観光協会（L1）→ 抽出0件**。市公式にも代替なし（レジャー等4か所を確認。キャンプ0回）
  - **富士河口湖町観光連盟（L1）→ 抽出0件**。町公式も観光を fujisan.ne.jp に委任していて代替なし。
    穴埋めに `SRC_YAMANASHI_KANKO_MTFUJI`（**L2**・富士河口湖町7件）を登録したが、**L1 の代替ではない**。
    **MISSING 43件を抱える主要エリアなので損失として残っている**
  - **川根本町（L1）→ 一覧5件は取れるが住所0件**（詳細が okuooi.gr.jp）
  - `officialUrl` **116件中22件**が読めなくなる（判定できる母数は94件）
- **403 は変わりうるので、解けたら気づける仕組みを入れた。**
  `check-muni-sources` と `check-official-urls` に `ROBOTS_403` 判定＋バナー。**件数が減れば復活**

### ★ UA は揃っていない（意図的）

```
district-sweep.js / check-official-urls.js / check-muni-sources.js … Chrome を名乗る
.parked-scan.js / l1-link-rot.js / robots-guard.js               … ClaudeBot
```

**「同じ UA でも取得層で結果が違う」と報告したのは誤りだった。UA が違っていただけ。**
実測（officialUrl 116件）: ClaudeBot は OK 92/403 23、Chrome は OK 114/403 **1**。

各スクリプトの先頭に「何を名乗るか」「なぜ揃っていないか」を明記済み。
