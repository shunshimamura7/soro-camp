## 3. ツールが自分で見つけた自分の穴（2つとも直した）

**どちらも「人が語彙を手で決める」という、このツールを作った理由そのものだった。**

### 3-1. キーワード表に観光系のローマ字が無かった

山梨市の観光ツリーは **`/site/tuorism/`**（**tourism の綴り誤り**）、
大多喜町は **`/kanko_iju_bunka/kanko_iju/kanko_jyouho/`**。
初版の KEYWORDS は `camp` / `stay` / `play` 等の英語と日本語しか持っておらず、
**`kanko` も `tourism` も入っていなかった。**

→ `観光` / `kanko` / `kankou` / `tourism` / `sightsee` / `shisetsu` / `公園` / `asobu` / `tomaru` 等を追加。

### 3-2. ★ それでも綴り誤りは救えない → **語彙に頼らない列挙を足した**

`tourism` を足しても **`tuorism` には当たらない。**
**キーワード一致は、相手が綴りを外した瞬間に沈黙する。**

そこで **「ディレクトリ構成（上位30／全N）」の節を新設**した。
**語彙を一切使わず、sitemap 中の URL のディレクトリを数えただけの表**で、
人が目で見て「ここが観光だ」と判断するための材料になる。
**`tuorism` はこの表に出た。**

あわせて、ディレクトリ型 CMS（大多喜町の502子）で
**子サイトマップの URL 自体をディレクトリ台帳として集計**するようにした
（踏まなかった子も構成としては数える。**踏むことと数えることを分ける**）。

## 4. ツールの限界（md にも毎回出る）

- **sitemap を出していないサイトでは何も測れない。**館山市公式・富津市公式・南部町公式が該当。
  HTML フォールバックは**トップから辿れるものしか出ない**ので、**0件を「無い」と読めない**
- **JS 描画の一覧は取れない。**伊東観光協会が該当（`/stay/` の中身が0件で返る）
- **`SKIPPED_ROBOTS_403` は「測っていない」。**山梨市観光協会が該当
- **キーワード表に無い語で分類されていれば取り逃す。**
  だから**ディレクトリ構成の表と、使ったキーワード一覧を毎回出力に含めている。**
  ヒット0を「無い」と読む前に、その2つを見ること
