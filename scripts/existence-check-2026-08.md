## 1. `asagiri-greenpark-camp`（朝霧高原グリーンパーク・富士宮市猪之頭1050）

- 「朝霧高原グリーンパーク」の名で予約・料金が出てくる一次情報は**皆無**
- 同名の実在は過去の総合レジャーランド（後に「朝霧高原温泉グリーンパーク」へ改称）。
  所在は富士宮市**麓**字浅野146 で、記録の「猪之頭1050」とは**別の大字**。2009年までに閉業し廃墟
- 猪之頭地区の実在キャンプ場は「朝霧高原オートキャンプ場」（**猪之頭2071**・なっぷ予約可）。
  名称も番地も一致しない**別施設**
- §18-7 のとおり、これは相対評価の母集団が変わって出てきた SUSPECT。施設側を調べた結果が上記

出典: haikyo.info/s/11395.html / nap-camp.com/shizuoka/11864 / inokashira.info/?page_id=426

## 2. `mitsumata-camp`（みつまたキャンプ場・山北町中川896）

- 完全一致検索で**全国どこにも施設がヒットせず**、予約・料金の一次情報ゼロ
- 中川896 は字小塚の一般地番とみられ、**実在施設の番地レンジのすぐ隣**
  （ウェルキャンプ西丹沢=868 / 大滝キャンプ場=879-4 / 西丹沢中川ロッヂ=897-111）
- 「ミツマタ」は西丹沢の有名モチーフ（三椏の群生地・ミツバ岳）。
  **地域の花名 + 実在住所レンジ + 連絡先なし + 座標9km逸脱**という合成の典型
- 町公式一覧13件に無いが、**それは根拠にしていない**（§17-7。一覧は実在2施設を落とす）

出典: town.yamakita.kanagawa.jp/0000000232.html / ootakicampsite.com ほか

## 3. `ito-marine-town-camp`（伊東マリンタウンキャンプ場・伊東市湯川571-19）

- 湯川571-19 は**道の駅「伊東マリンタウン」**の所在地。運営会社の施設一覧
  （商業棟・スパ棟・マリーナ等）に**キャンプ場・テントサイト・RVパークは無い**
- 公式サイト自身が「伊豆のキャンプ場」紹介ページで**車で8分の他施設（宇佐美城山公園
  キャンプ場等）へ案内**している。敷地内にあるなら他所を案内しない
- 記録の tel 0557-38-3523 は**マリンタウンのどの番号とも一致せず**、検索ヒットもゼロ
- **証拠の格は hadano-togawa-camp と同じ**（施設の管理者自身の一覧に無い）。
  決着させるなら道の駅 0557-38-3811 に電話1本（「テント泊できる施設はあるか」）

出典: ito-marinetown.co.jp/about/ / ito-marinetown.co.jp/sitescene/izu/izucamp/

## 4. `makioka-fruits-camp`（牧丘フルーツ村キャンプ場・山梨市牧丘町牧平3041）

- 完全一致で返るのは**千葉県君津市の「オートキャンプ・フルーツ村」**（fruitsvillage.com・
  君津市公式にも掲載）のみ。山梨県内に同名施設の予約・料金情報は皆無
- 牧丘の実在キャンプ場（琴川・マキオカネイチャークラブ・笛吹小屋等）のどれとも一致しない。
  牧平3041 に該当する施設も特定できず
- **県をまたいだ実在施設名の借用**。§6-16 の「データ外からの借用」に住所でなく**名前**で
  当たった例（address-borrow-check の一致検査には原理的に出ない）

出典: city.kimitsu.lg.jp/site/kanko/2127.html / fruitsvillage.com / jalan.net の山梨市一覧

## 5. `kabutomushi-mori-camp`（かぶと虫の森キャンプ場・相模原市緑区牧野4015）

- 相模原市観光協会公式のキャンプ場一覧**24施設に無い**（牧野地区は亀見橋バカンス村のみ）
- 「かぶと虫の森」で予約・料金が出るのは**三重県**のカブトムシ採集イベント（宿泊施設ではない）
- なっぷ・じゃらんにも該当なし。牧野4015 の検索ヒットもゼロ。県不一致の座標（9.8km）と整合
- district-sweep の SELF_TEST（案B）に「実在側に出ない名前」として焼き込んだ。
  もしソース側に現れたら SELF_TEST が落ちて、この判断の見直しを強制する

出典: e-sagamihara.com/camp/ ほか

## 7. `wadanagahama-kaigan`（CITY_MISMATCH）

- 三浦市観光協会公式の所在地表記「三浦市初声町和田」と**記録は一致**
- ただしこの浜は**真ん中に三浦市・横須賀市の市境**がある。北側は「長浜海岸」（横須賀市長井）、
  南側が和田海岸（三浦市）。記録座標は横須賀側を指すとみられる → **誤りは座標側**
- → 実ピンは**三浦市側（和田浜駐車場・和田海岸側）に置く**こと。
  北端に置くと CITY_MISMATCH が再発する（市境またぎ地形なので構造的に出やすい）

出典: miura-info.ne.jp/sightseeing/beach-2/ / miurahantou.jp/wada-nahama-kaigan/
