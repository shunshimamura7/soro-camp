## 1. 前回（2026-08-15）が「無い」と結論した理由と、その誤り

`sweep-tsuru-2026-08.md` の L1-B は、`tsurukankou.jp` について
**「サイトのタクソノミーを sitemap から数えた結果、キャンプのカテゴリは存在しない」**と結論していた。
数えたのは2本だけだった。

| 前回数えたもの | 中身 | 判定 |
|---|---|---|
| `category-sitemap.xml` | `news` のみ | キャンプ無し ✅ 事実 |
| `discoverycat-sitemap.xml` | `spot` / `gourmet` / `hotel` / `shopping` の4件 | キャンプ無し ✅ 事実 |

**どちらも正しい。だが `sitemap.xml` はタクソノミー系を8本持っている。**

```
category-sitemap.xml     featurecat-sitemap.xml    walkingcat-sitemap.xml   discoverycat-sitemap.xml
post_tag-sitemap.xml     featuretag-sitemap.xml    walkingtag-sitemap.xml   discoverytag-sitemap.xml
                                                                            ^^^^^^^^^^^^^^^^^^^^^^^^
```

**見ていなかった `discoverytag-sitemap.xml` に44タグあり、その1つが「キャンプ」だった。**

> **教訓: 「カテゴリに無い」は「タクソノミーに無い」ではない。**
> 一覧の不在を結論にするときは、**タクソノミーを1本ずつ潰した記録を残すこと。**
> 前回の記述は「2本を見て無かった」を「無い」と書いていた。
> これは §6-7（自治体の一覧に無い＝存在しない、は成り立たない）の探索側での同型。

## 4. ★ 網羅率は 0% と出た。**それでも登録は妥当**（数字の読み方）

sweep が出した網羅率はこうなっている。

| L1 | 一覧の件数 | 実在確実 | うち掲載 | 網羅率 |
|---|---|---|---|---|
| 都留市観光協会 つるのルーツ発掘巡り キャンプ | 7 | **1** | 0 | **0%** |

**分母が1件しかない。**「実在確実」の定義は `priceVerified: true` かつ `needsVerify` 無しで、
都留市でこれを満たすのは `nagomino-sato-tsuru` だけ（`takaranoyama-fureai` は closed）。
その1件が §3-3 のとおり L1 では別名義で載っているため、名寄せに失敗して 0/1 = 0% になっている。

**前回の「50%」とこの「0%」は別の母集団の数字で、直接比べてはいけない**（§18-7 と同じ型）。

| | 前回（2026-08-15） | 今回（2026-08-18） |
|---|---|---|
| 対象 L1 | 市公式「自然体験・キャンプ」 | 観光協会「キャンプ」タグ |
| 分母 | **既知の実在施設4件**（手で数えた） | **DB の実在確実レコード1件**（機械） |
| 率 | 50% | 0% |

**結論: `ORPHAN_TRUST_MIN = 0.7` には届かない。よって都留市の ORPHAN は今回も判定に使えない。**
sweep の md にもそう出ている（「網羅率 70% 以上の L1 が1つも無い」）。

**登録の根拠は ORPHAN ではなく MISSING の検出力。**
登録前、都留市の民間キャンプ場は L2 の confidence LOW/MID でしか出てこなかった。
登録後は **大沢オート・FISH ON!鹿留・すげのレジャー・鹿留オートが L1 出典の HIGH** になり、
「一次情報が観光協会にある」ことが機械で見える状態になった。**これが登録の効果。**
