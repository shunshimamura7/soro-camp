# `nekumasanso-auto`（福士川根熊山荘ファミリーオートキャンプ場）の座標確定（2026-08-11）

`needsCoord` の最後の1件。Googleマップ上で施設が2つに割れており、
データ名（「福士川」＋「根熊山荘」）が**両方を含んでいる**ため、どちらを座標にするか確定が要った。

## 判定: **候補B（根熊山荘）を採る。候補Aは別施設だった**

| | ラベル | 座標 | 判定 |
|---|---|---|---|
| 候補A | 福士川オートキャンプ場 | 35.2211908, 138.4768309 | **別施設。採らない** |
| **候補B** | **根熊山荘** | **35.2188515, 138.4770251** | **採用** |

2点は約260m差で、どちらも逆ジオは「山梨県 / 南部町 / 福士」（標高 135.2m / 142.6m）。
**GSI では大字までしか出ないので機械では分離できない。**一次情報で切り分けた。

## 確認できたこと

### 1. キャンプ場は民宿「福士川根熊山荘」の敷地内にある

施設公式 https://hukusshigawacamp.eyado.net/

> **民宿福士川根熊山荘の敷地内にあり**、サイトの横を清流福士川が流れている

同サイトの `4928.html` は見出しが
「**民宿 福士川根熊山荘 [福士川根熊山荘ファミリーオートキャンプ場]**」で、
**住所も電話も同じ**（南部町福士15854 / 代表・FAX 0556-66-3241 / 予約 070-4168-0207）。

**「民宿と別のキャンプ場」ではなく、民宿の敷地がそのままキャンプ場**という関係。
だから民宿のピン（候補B）がこの施設の本体で、データの住所 15854 と対応する。

### 2. 「福士川オートキャンプ場」は同じ南部町福士にある**別の施設**だった

**山梨県公式観光ネット（県公式）が2件を別々に列挙している。**
https://www.yamanashi-kankou.jp/special/yamanashicamp/fujikawa.html

```
福士川根熊山荘ファミリーオートキャンプ場（南部町）  → /kankou/spot/p2_3116.html
福士川オートキャンプ場（南部町）                    → /kankou/spot/p2_3118.html
```

（スポット詳細ページはどちらも現在404。一覧側に別項目として残っている）

住所と電話も違う。

| | 福士川**根熊山荘**ファミリーオートキャンプ場 | 福士川オートキャンプ場 |
|---|---|---|
| 住所 | 南部町福士**15854** | 南部町福士**15691-1**（じゃらん）／**19867**（なっぷ） |
| 電話 | **0556-66-3241**（予約 070-4168-0207） | **0556-66-2272** |
| 料金 | — | オート1区画 車1台5人まで5,000円 |
| 営業 | — | 4月1日〜12月31日 |

**⚠ 予約サイト間でも番地が割れている**（15691-1 と 19867）。
どちらにせよ **15854 ではない**ので、別施設であることは動かない。

**候補A を採ると、名前が似ている別施設の座標を取り込むことになる。**
§6-18 の「アグリゲータは名前が似ていれば別施設の情報を紐づける」と同じ型が、
**Googleマップのピンでも起きる**。§13-1 の `saiko-tsuhara-camp`、
`batch-2026-05-26-check.md` の `kumomi-auto`（雲見夕陽と潮騒の岬＝別施設）に続いて3例目。

### 3. 正式名称は現データのままで正しい

施設公式のタイトル・本文とも「**福士川根熊山荘ファミリーオートキャンプ場**」で、
`data` の `name` と完全一致。**変更しない。**

南部町は L1_NOT_FOUND（§5 の L1 網羅率表）なので自治体公式の一覧は無く、
県公式のスポット詳細も404だったため、施設公式が最上位の出典になる。
