道志村は **L1 網羅率75%**で ORPHAN を判定として読める2市町村の1つ。
**その一覧に載っていることの重みは他の地区より大きい。**

**2. district-sweep の道志村の結果 → ORPHAN ではなく IN_DATA だった**

```
| `sankoso-auto` 山光荘オートキャンプ場 | 山光荘オートキャンプ | 名前 | HIGH | L1 |
```

**名前で一致していたので、検査には何も出ていなかった。**
`district-sweep.js` は名前と大字で突き合わせる。道志村は大字が無いので、
**住所の番地が違っても IN_DATA になる。**この型は今の検査では拾えない。

**3.「山光荘オートキャンプ」の市町村 → 道志村で確定**

施設公式 https://www.sanko2400.com/ でも
「山梨県南都留郡道志村11777 / 090-3059-1777」。村公式と一致。
**独立した2ソースが同じ住所と電話を出している**（§6-15 の意味で使える一致）。

**4. 住所「道志村5347」に何があるか → 村公式の31件には無い**

近い地番は `5073`（貸し別荘 となり）と `5334`（大栗オートキャンプ場）。
**5347 はどの施設のものでもない。**
§6-16 の「捏造」型（実在する大字＋どこの施設のものでもない番地）に当てはまる。
道志村は大字を持たないので、番地だけが手がかりになる。

## 検査への示唆

**`district-sweep.js` はこの型を拾えない。**

名前が一致していれば IN_DATA になり、住所の番地が違っても何も出ない。
とくに**道志村のように大字を持たない市町村では、番地の誤りを検出する手段が無い**
（`verify-address-gsi.js` は NO_OAZA になり、大字での突き合わせができない）。

**今回これが見つかったのは、座標の目視取得で1件ずつ現物に当たったから。**§6-27。
機械検査からは PREF_MISMATCH（座標がずれている）としか見えていなかった。

**実際に他にもあった。**上の副産物のとおり `okudoshi-auto` が同じ型だった。

**`tel` と `address` を L1 の一覧と突き合わせる検査を書けば、機械で拾える。**
今回は道志村を手で突き合わせて2件見つかった。同じことを他の市町村でもやる価値がある。
ただし**その検査が成立するのは L1 が住所を持っている市町村だけ**で、
`--l1-audit` で住所が取れているのは相模原市・山北町観光協会・川根本町・
富士河口湖町・山中湖村・道志村・厚木市・松田町（＝L1 のある8市町村）に限られる。
