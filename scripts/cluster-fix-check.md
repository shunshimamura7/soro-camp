# 清里3件・銀河もみじ・丹沢湖ロッヂ 調査レポート

調査日: 2026-08-07
対象: `scripts/coord-cluster-check.md` の所感で優先1〜3に挙げた件

**このレポートの作成中、`data/campgrounds.json` は一切変更していない。**

## 調査の方針

`scripts/sea-coord-check.md` と同じ。

- 座標は **GoogleマップのURL内に書かれた値のみ**を採用する
- 採用候補は必ず**国土地理院の逆ジオコーディング**にかけ、市区町村・大字がデータの住所と一致するかを確認する
- 標高も取得し、その土地の高さとして妥当かを見る

検証には `scripts/check-one-coord.js` を使った。**今回 `--pref=` オプションを追加した。**
これが無いと「市区町村が引けた＝OK」としか言えず、**清里3件のように隣県に落ちているケースを OK と表示してしまう**ため。実際、最初の実行では3件とも「OK」と出ていた。

### 1c. まきば公園キャンプ場 — `makiba-kogen-camp`

**判定: NOT_FOUND — 座標以前に、施設の実在が確認できない**

調べたところ、**「まきば公園」はキャンプ場ではなかった。**

- [県立まきば公園（富士の国やまなし観光ネット）](https://www.yamanashi-kankou.jp/kankou/spot/p2_4890.html) の住所は **北杜市大泉町西井出8240-1**。
  データの「北杜市高根町清里3545-1」とは**町名から違う**
- 同ページの `maps.google.com/maps?q=35.923254,138.408251` を検証すると
  「山梨県 / 北杜市 / **大泉町西井出**」標高1,429.3m。データの座標から約4.9km離れている
- まきば公園は**県立八ヶ岳牧場の一部に作られた公園**で、ポニーや羊とふれあう施設。
  **営業時間 9:00〜17:00、入場無料、冬季（11/10〜4/19）閉鎖。** テント宿泊の施設ではない
- **「まきば公園キャンプ場」で検索しても、山梨県の該当施設は1件も出てこない。**
  出てくるのは千葉県袖ケ浦市の「森のまきばオートキャンプ場」という別施設だけ
- データの `priceMin: 2500` / `priceMax: 5000` / `season: 4月〜11月` を裏付ける情報も見つからない

#### 住所の出どころについて

データの住所「高根町清里**3545-1**」は、`kiyosato-oka`（清里丘の公園キャンプ場）の「高根町清里**3545-5**」と**枝番だけが違う**。
実在するまきば公園の住所（大泉町西井出8240-1）とはまったく別物なので、**隣の記録から住所を流用して作られた可能性がある。**

伊東マリンタウンと同じ構図。座標を直しても「実在しない施設を正しい位置に置く」ことにしかならない。

**推奨:** `status: 'unverified'` ＋ `needsVerify: true` に落として一覧から外す。
その上で、同じ住所にある「パノラマ温泉オートキャンプ場」（甲斐大泉パノラマの湯・いずみ荘が受付）と取り違えていないかを確認したい。

## 2. 銀河もみじキャンプ場 — `ginga-momiji-camp`

**判定: OUT_OF_SCOPE — 座標は正しい。掲載範囲の問題**

### 実在する施設は長野県阿智村のもの

| 項目 | 内容 |
|---|---|
| 住所 | **長野県下伊那郡阿智村浪合1771-1** |
| 電話 | 0265-48-6058 |
| 公式 | [ginga-momiji.camp](https://ginga-momiji.camp/) / [momijidaira.com](https://momijidaira.com/) |
| 料金 | テントサイト 5,000円〜／バンガロー 6,500円〜／グランピング 15,000円〜 |
| 営業 | 4月末〜11月初旬。水曜定休（7〜8月は無休） |
| 特徴 | 「日本一の星空」。環境省の星空観測に適した場所として全国1位 |

**データの座標 35.3677773, 137.6685038 は、この阿智村の施設として正しい。**
国土地理院の逆ジオも「長野県 阿智村 浪合」を返す。つまり**座標だけが正しく、それ以外が全部ずれている**。

### 静岡県川根本町に同名・類似名の施設は見つからなかった

「川根本町 キャンプ場 星空 天の川 もみじ 銀河」で検索しても、返ってくるのは阿智村の銀河もみじキャンプ場ばかりで、**川根本町側に同名・類似名の施設は1件も出てこなかった。**

したがって「川根本町の施設として登録されたのが誤り」という見立てが正しい。

### データとの食い違い

| フィールド | データの値 | 実在施設（阿智村） |
|---|---|---|
| `prefecture` | **静岡** | 長野 |
| `area` | **川根本町** | 下伊那郡阿智村 |
| `address` | **（なし）** | 長野県下伊那郡阿智村浪合1771-1 |
| `priceMin` / `priceMax` | **2,000 / 4,000** | テント5,000円〜 |
| `season` | **通年** | 4月末〜11月初旬、水曜定休 |
| `tel` / `officialUrl` | **どちらも空文字** | 0265-48-6058 / ginga-momiji.camp |
| `soloComment` | 「**川根本町の山奥**、天の川がはっきり見えるほど空が暗い」 | — |
| `lat` / `lng` | 35.3677773, 137.6685038 | **正しい** |

`soloComment` の「川根本町の山奥」は事実と違う。一方で「天の川がはっきり見える」は阿智村の施設の特徴としては合っている。
**阿智村の施設情報に、川根本町という誤った所在地を貼り付けて作られた記録**に見える。

### 判断材料（削除するか、掲載範囲を広げるか）

**削除する場合**

- サイトの掲げる範囲は「神奈川・静岡・山梨」。`lib/types.ts` の `prefecture` は
  `"神奈川" | "静岡" | "山梨"` のユニオン型で、`validate-data.js` も
  `prefecture-bounds.js` の3県以外をエラーにする。**長野を足すには型と検証の両方に手を入れる必要がある**
- 座標の県境チェック（`isOutOfBounds`）も長野県の緯度経度範囲を追加しないと通らない
- 現状この1件だけのために3県構成を崩すことになる
- サイト名・説明文（「神奈川・静岡・山梨のソロキャンプ場を徹底比較」）も書き換えが要る

**掲載範囲を広げる場合**

- 阿智村は「日本一の星空」で知られ、ソロキャンパーの目的地としての訴求力は高い
- ただし静岡・山梨からのアクセスは良くない（阿智村は長野県南部、中央道園原ICが最寄り）
- 長野を足すなら1件だけでは中途半端で、長野の他の施設も入れないと
  「長野タブに1件しかない」状態になる

**第3の選択肢**

- `prefecture` を長野にせず、`status: 'closed'` でも `'unverified'` でもなく、
  **記録ごと削除する**のが最も素直だと考える。掲載範囲外の施設が1件だけ紛れている状態は、
  ユーザーから見ると「なぜこれだけ長野？」という説明のつかない例外になる
- 将来的に長野へ広げるときに、改めて正しい情報で登録し直せばよい

判断は保留する。

### 3b. `tanzawako-roadside-camp`（丹沢湖ロッヂ）— DUPLICATE

**判定: `tanzawako-lodge` と同一施設**

`duplicate-check.js` の対象条件から `coordsVerified` の縛りを外したところ、このペアが検出された。

> `tanzawako-lodge`「丹沢湖ロッヂキャンプ場」× `tanzawako-roadside-camp`「丹沢湖ロッヂ」
> — 名称完全一致（編集距離0）、4.35km

|---|---|---|
| `name` | 丹沢湖ロッヂキャンプ場 | 丹沢湖ロッヂ |
| `address` | 神奈川県足柄上郡山北町玄倉514 | **（なし）** |
| `tel` | 0465-78-3156 | **（空文字）** |
| `officialUrl` | **（なし）** | **https://tanzawakolodge.com/** |
| `lat` / `lng` | 35.4688, 138.9808（山梨県道志村） | 35.435, 139.005（山北町・標高600.8m） |
| `priceMin` / `priceMax` | 4,950 / 8,000 | 2,500 / 4,000 |
| `lastVerified` | 2026-05-26 | 2026-08-06 |
| `needsVerify` | なし | **true** |
| `soloComment` | 玄倉川清流沿いに分散するサイト配置 | 都心から90分、富士山と湖を一望できる高台。焚き火・直火は全面禁止 |

**`tanzawako-roadside-camp` の `officialUrl`（tanzawakolodge.com）が指す先の住所・電話が、`tanzawako-lodge` の `address`・`tel` と完全に一致する。** 同一施設で確定と考えてよい。

**2件は互いを補完している。** 片方は住所と電話を持ち、もう片方は公式URLを持つ。
どちらの座標も誤り（一方は山梨県、一方は標高600mの山中）で、**正しい座標はどちらも持っていない**。

#### 統合するときの推奨

| フィールド | 採用する値 | 理由 |
|---|---|---|
| `slug` | `tanzawako-lodge` | 既存リンクの数が読めないが、より古くからある側 |
| `name` | **丹沢湖ロッヂ** | 公式サイトの表記。「キャンプ場」は付いていない |
| `address` / `tel` | `tanzawako-lodge` の値 | 公式サイトと完全一致 |
| `officialUrl` | `https://tanzawakolodge.com/` | `tanzawako-roadside-camp` から持ってくる |
| `lat` / `lng` | **35.4158351, 139.06893615** | 本調査で確定 |
| `priceMin` | **4,950** | 入場料1,650＋オート1区画3,300。公式の料金表と一致 |
| `priceMax` | 要検討 | 公式はバンガロー4,400円〜、ロッヂ3,300円〜。区分ごとに拾い直したい |
| `soloComment` | 要書き直し | 2件の記述が食い違う。とくに**焚き火・直火の可否は公式で確認が必要** |

**`tanzawako-roadside-camp` の「焚き火・直火は全面禁止」という記述は、統合前に裏を取るべき。**
`tanzawako-lodge` 側にはこの記述がなく、片方だけが持つ情報としては影響が大きい。

判断（どちらの slug を残すか、統合するか片方を closed にするか）は保留する。

## 5. 所感

### 「塊」の中身は一様ではなかった

清里3件は「まとめて同じ方向にずらされた塊」に見えていたが、開けてみると**座標の誤り2件と、実在しない施設1件**だった。
ずれの量も1.4kmと2.1kmで揃っていない。**クラスタ検出は「ここを見ろ」という当たりを付けるまでが役割で、原因が同じとは限らない。**

一方で、当たりの付け方としては有効だった。清里3件は全部 `coordsVerified: true` が立っていて、
このフラグを信じる運用のままなら3件とも見つからないままだった。

### 実在しない施設が、これで3件目

- `sanogawa-camp`（佐野川河川公園、キャンプ禁止）
- `ito-marine-town-camp`（伊東マリンタウン、道の駅の紹介ページを施設と取り違え）
- `makiba-kogen-camp`（まきば公園、キャンプ場ではない公園）

**3件とも「実在する何か」の名前や住所を借りて作られている。** まきば公園に至っては、
隣の記録（清里丘の公園、3545-5）から枝番だけ変えた住所（3545-1）が入っていた。

一括投入の元データに、実在確認を伴わない候補が混ざっていた可能性が高い。
`needsVerify` が立っていない施設のうち、**電話番号も公式URLも持たないもの**を洗い出すと、
同種の記録がまとめて見つかるかもしれない。`ginga-momiji-camp` も `tel`・`officialUrl` が
どちらも空文字だった。

### 検証ツールの穴が2つ見つかった

**1つ目。`check-one-coord.js` が県の一致を見ていなかった。**
清里3件を最初に流したとき、3件とも「OK」と表示された。市区町村が引けたかどうかしか見ておらず、
長野県に落ちていることを検出できていない。`--pref=` を追加して直した。
`verify-coords-gsi.js` は最初から `PREF_MISMATCH` を出していたので、**単発検証ツールのほうが甘かった**形。

**2つ目。`duplicate-check.js` が `coordsVerified: true` を対象外にしていた。**
今回この縛りを外したところ、丹沢湖ロッヂのペアが検出された。
同じデータで比較すると **10ペア → 133ペア（+123、消えたものは0）**。

ただし増えた123ペアの大半は誤検出だった。「富士」「朝霧」「山中湖」「PICA」といった
地名・ブランド名の共通部分が3文字以上あれば拾ってしまうため、S/N比は明らかに落ちている。
**縛りを外したこと自体は正しいが、判定基準の側を締めないと使いにくい。**

拾えた本物は次の2つだった。

| ペア | 根拠 |
|---|---|
| `nakatsugawa-camp` × `nakatsugawa-kasenjiki` | 座標が **0.00km**（完全一致） |
| `tanzawako-lodge` × `tanzawako-roadside-camp` | 名称完全一致（編集距離0） |

判定基準の案としては、「名前の共通部分が3文字以上」だけで拾うのをやめ、
**共通部分が施設名の主要部（「キャンプ場」「オートキャンプ場」等の一般語を除いた部分）に
かかっているかを見る**か、共通部分の長さの閾値を上げる。
現状は `normalizeName` が一般語を落としきれていないのが効いていると見える。
