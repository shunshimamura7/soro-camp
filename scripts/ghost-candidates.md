### 代わりに、はっきりした塊が1つ見つかった

**「住所が空」の76件と、「priceNote（料金の内訳）が無い」76件は、完全に同一の集合だった。**

```

  うち 住所も空: 76
  うち 住所はある:  0
priceNote あり かつ 住所空: 0
```

重なりが偶然ここまで一致することはない。**同じ一括投入バッチで入った76件**と見てよい。

この76件は、料金の値（`priceMin` / `priceMax`）は持っているのに内訳を持たない。
料金を実際に調べた人は必ず「入場料◯円＋サイト料◯円」のような内訳を書く。
値だけあって内訳が無いのは、**調べずに置かれた値**の疑いが強い。

実際、重点候補27件の料金は定型的だった。

| 料金の組 | 件数 |
|---|---|
| 2,500〜3,500 | 9件 |
| 3,000〜4,500 | 3件 |
| 2,000〜3,000 | 3件 |
| 3,500〜5,000 | 3件 |
| 5,000〜7,000 | 2件 |

27件が12通りの組しか持たず、74%が他と重複する組に入っている。**キリの良い数字だけで構成されている**点も含めて、実額ではなく推定値が入っていると考えるのが自然。
